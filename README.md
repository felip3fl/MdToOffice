## 📃 Descrição do projeto

<p align="justify">
 Projeto desenvolvido em C# com o propósito de copiar conteúdo HTML para o Clipboard do Windows, permitindo que o conteúdo seja colado no Microsoft Word mantendo a estrutura e a formatação definida no HTML e CSS.
</p>



<BR>

## :hammer: Funcionalidades do projeto

- `Funcionalidade 1`: Criar conteúdo HTML com estilos CSS incorporados.
- `Funcionalidade 2`: Preparar o HTML no formato esperado pelo Clipboard do Windows.
- `Funcionalidade 3`: Copiar o conteúdo HTML formatado para o Clipboard.
- `Funcionalidade 4`: Disponibilizar uma versão em texto simples como conteúdo alternativo do Clipboard.
- `Funcionalidade 5`: Permitir a colagem do conteúdo formatado diretamente no Microsoft Word usando `Ctrl+V`.

<BR>

## 📁 Acesso ao projeto

Todo código fonte se encontra na pasta **MdToOffice**.

O arquivo principal da aplicação é o **Program.cs** e o projeto é definido pelo arquivo **MdToOffice.csproj**.

<BR>

## 🛠️ Abrir e rodar o projeto

Use o **Visual Studio 2022** ou outro ambiente compatível com **.NET 10** para abrir a solução.

### Execução

1. Abra o arquivo `MdToOffice.slnx`.
2. Compile e execute o projeto `MdToOffice`.
3. A aplicação copiará o conteúdo HTML definido no código para o Clipboard.
4. Abra o Microsoft Word.
5. Pressione `Ctrl+V` para colar o conteúdo mantendo a formatação HTML/CSS.

O projeto utiliza Windows Forms para acessar o Clipboard e, portanto, deve ser executado em ambiente Windows.
